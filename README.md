## ⚡ Ключевые возможности

### 🛍️ Для покупателей
- **Каталог 1 500+ архивных позиций**: худи, свитшоты, олимпийки, куртки, футболки, джинсы, штаны, аксессуары и обувь.
- **Статусы наличия**: наглядные бейджи `🟢 В НАЛИЧИИ` и `🔴 ПРОДАНО`.
- **Мгновенный умный поиск**: поддержка поиска по нескольким словам одновременно (например, `adidas худи`, `куртка xl`, `джинсы 50`) вне зависимости от порядка слов.
- **Быстрый заказ у Никиты 🛹**: клик по кнопке заказа открывает диалог в Telegram с автоматически составленным сообщением (название, размер, цена в BYN и прямая ссылка на вещь). Для проданных вещей доступна кнопка «Спросить у Никиты похожую вещь».
- **Личный блокнот «Хочу померить» и «Избранное»**: сохранение понравившихся вещей в браузере для примерки в шоуруме с автоматической очисткой устаревших ID.
- **Фирменный стиль**: тёмная гранж/скейт эстетика с парящими маскотами-зомби на фоне.

## 🚀 Локальный запуск и разработка

### Требования
- Node.js ≥ 20 или Bun

### Установка зависимостей
```bash
npm install
```

### Запуск режима разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:5173`.

### Сборка проекта
```bash
npm run build
```
Создаётся оптимизированный бандл в папке `dist/`.

│   ├── context/
│   │   └── StoreContext.tsx   # Глобальный стейт, учёт наличия, защита сессии
│   ├── data/
│   │   └── seedProducts.ts    # Каталог 1 500+ позиций из ВК
│   ├── pages/
│   │   ├── HomePage.tsx       # Главная витрина
│   │   ├── CatalogPage.tsx    # Каталог с фильтрами, пагинацией и поиском

│   │   ├── AboutPage.tsx      # Информация о шоуруме и доставке
│   │   └── AdminPage.tsx      # Панель сотрудников: учёт наличия и смена пароля
│   └── utils/
