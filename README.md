# 🧟 Лавка Зомби — Каталог селективной архивной одежды

Веб-приложение для культового селективного магазина винтажной и архивной одежды **«Лавка Зомби»** (Минск). Платформа оптимизирована для ультрабыстрой загрузки каталога, удобного поиска по 1 490+ вещам, проверки наличия в шоуруме и моментального оформления заказа в Telegram.

## ⚡ Ключевые возможности

### 🛍️ Для покупателей
- **Каталог 1 490+ архивных позиций**: худи, свитшоты, куртки, олимпийки, свитера, джинсы, футболки, обувь и свежие аксессуары (Oakley, Carhartt, Patagonia, Kodak, Slipknot, Nirvana).
- **100% локальные WebP-фотографии**: все фотографии оптимизированы и хранятся локально внутри проекта, обеспечивая моментальную загрузку без внешних зависимостей.
- **Умная адаптивная фильтрация**:
  - Мультивыбор размеров (можно выбрать несколько размеров одновременно, например `M` + `L`).
  - Раздельные размерные сетки: при выборе категории **«Обувь»** фильтр автоматически показывает европейские размеры (**36–49 EU**), а для одежды — стандартные (**XS–XXL, ONE SIZE**).
  - Интерактивный фильтр диапазона цен с быстрыми пресетами (`< 50 BYN`, `50–100 BYN`, `100+ BYN`).
- **Мгновенный поиск**: регистронезависимый поиск по нескольким ключевым словам (бренд, тип, размер, цвет).
- **Заказ в Telegram в 1 клик**: нажатие на кнопку **«Заказать»** автоматически генерирует предзаполненное сообщение с названием вещи, размером, ценой и прямой ссылкой в Telegram-чат магазина. Для проданных вещей доступна кнопка «Спросить похожее».
- **Корзина и блокнот примерок**: сохранение понравившихся вещей для примерки в шоуруме.
- **Фирменная skate / Y2K эстетика**: лаконичный тёмный интерфейс, динамичные зомби-маскоты и отсутствие навязчивых рекламных лозунгов.

### 🛡️ Панель управления и склад (Admin)
- **Страница входа**: `/admin`
- **Безопасная аутентификация**:
  - Хэширование паролей по алгоритму **SHA-256 с криптографической солью** (Web Crypto API).
  - Защита от перебора: блокировка входа на 15 минут после 5 неверных попыток ввода.
  - Сохранение сессии на 7 дней.
  - Возможность смены пароля на собственный во вкладке «Настройки».
- **Данные для входа по умолчанию**:
  - **Логин:** `zombie_boss` (также поддерживаются `nikita`, `lz_minsk`, `nikita_zombie`, `zombie_owner`)
  - **Пароль:** `ZombieMinsk2026!`
- **Управление вещами и складом**:
  - Моментальное переключение статуса наличия: `[ 🟢 В наличии ]` ⇄ `[ 🔴 ПРОДАНО ]`.
  - **Добавление новых товаров**: загрузка фото с мобильного телефона или ПК, указание замеров, категорий и цен.
  - **Serverless Git-бэкенд**: новые товары и загруженные фото через `/api/products` автоматически фиксируются в репозитории проекта на GitHub для сохранности на всех устройствах.
- **Управление витриной**:
  - Редактирование текста и бейджа промо-строки с анонсами новых дропов.
  - Настройка главного баннера и заголовка витрины.

## 🛠️ Стек технологий

| Компонент | Технологии |
|-----------|------------|
| **Фронтенд** | React 19, TypeScript, Tailwind CSS, Lucide Icons |
| **Сборщик** | Vite 8, Node.js |
| **Серверная часть** | Vercel Serverless Functions (`/api/products`), GitHub REST API |
| **Криптография** | Web Crypto API (Salted SHA-256) |
| **Хранилище данных** | JSON Seed DB (`seedProducts.json`) + Git-based Custom DB + LocalStorage |
| **Хостинг & CDN** | Vercel Edge Network ([lavkazombie.vercel.app](https://lavkazombie.vercel.app/)) |

## 🚀 Локальный запуск и разработка

### Требования
- Node.js ≥ 20

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Локальный сервер запустится по адресу: `http://localhost:5173`

### Проверка типов и сборка
```bash
# Проверка типов
npx tsc --noEmit

# Оптимизированная production-сборка
npm run build
```

## 📁 Структура проекта

```
zombie/
├── api/
│   └── products.ts            # Serverless функция Vercel (Git-бэкенд добавления товаров)
├── public/
│   ├── assets/
│   │   ├── products/          # Локальные WebP-фотографии всех 1 490+ вещей
│   │   └── uploads/           # Загруженные фотографии новых товаров
│   └── data/
│       ├── seedProducts.json  # Основная база каталога
│       ├── customProducts.json# База добавленных через админку вещей
│       └── heroSettings.json  # Настройки витрины и промо-строки
├── src/
│   ├── components/            # UI-компоненты (Header, ProductCard, AdminModal и т.д.)
│   ├── context/
│   │   └── StoreContext.tsx   # Глобальное состояние каталога, корзины и фильтров
│   ├── pages/                 # Страницы (HomePage, CatalogPage, AdminPage и др.)
│   ├── types/
│   │   └── store.ts           # TypeScript типы, категории, сетки размеров (EU 36-49, XS-XXL)
│   └── utils/
│       ├── adminAuth.ts       # Авторизация администратора, соленый SHA-256, lockout
│       └── storeLogic.ts      # Форматирование цен BYN/RUB, фильтрация и валидация
├── vercel.json                # Конфигурация роутинга и рерайтов Vercel
└── README.md
```
